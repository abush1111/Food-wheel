# 🍽️ 今天吃什么

一个简洁的食物决策转盘，帮你解决"中午吃什么"的世纪难题。

## ✨ 功能

- 🎯 转盘随机选择
- 🔐 真随机数（Web Crypto API）
- 🔊 音效反馈
- 📊 转到次数统计
- 💾 本地数据存储
- 🎲 一键随机填充
- 📱 响应式设计

## 🎨 设计

- 莫兰迪奶油系配色
- 极简风格
- 高 DPI 清晰显示

## 🚀 使用

直接打开 `index.html` 即可运行，无需后端。

```bash
# 或者用本地服务器
python -m http.server 8000
```

## 📁 项目结构

```
├── index.html    # 页面结构
├── script.js     # 核心逻辑
└── style.css     # 样式设计
```

## 🛠️ 技术栈

- HTML5 Canvas
- CSS3 动画
- JavaScript ES6
- Web Audio API
- Web Crypto API
- localStorage
